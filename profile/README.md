## What is UserBenchmark?

UserBenchmark operates as a portable system evaluation utility designed to measure hardware performance and assess component responsiveness across Windows PCs. Desktop builders, hardware enthusiasts, and system administrators utilize this lightweight tool to conduct swift performance tests on central processors (CPU), graphics cards (GPU), system memory (RAM), and storage drives (SSD/HDD/USB) without undergoing extensive installation setups.

Integrating this evaluation utility into routine hardware troubleshooting procedures allows users to compare individual component speeds against aggregate global test results. The application executes a sequence of synthetic workload tasks—such as 3D graphics rendering, floating-point math operations, sequential/random drive reads, and memory latency tests—to pinpoint thermal throttling or misconfigured hardware profiles. Upon test completion, UserBenchmark generates a detailed browser report categorizing system capability into relative Gaming, Desktop, and Workstation performance tiers.

|---------|-------------|

| **Comparative Hardware Metrics** | Compares component scores against millions of user-submitted benchmarks to identify underperforming hardware. |

## 📥 Installation & Usage Guide

- Download the lightweight executable using the button above.
- Close background applications and browser windows to ensure accurate test scores.
- Launch `UserBenchmark.exe` on your target Windows PC.
- Select the hardware components you wish to analyze and click **Run**.
- Review the generated browser report to inspect component rankings and operational status.
